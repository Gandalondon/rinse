# Rinse portfolio assets

Screens are 1125 x 2436 (375 x 812 at 3x), no phone frame, rebuilt from the app's own layout, type and colours (Geist, Theme.kt, Screens.kt). Widgets are on transparent backgrounds at 3x.

## Copy (gandalondon.com/work/rinse)

Teaser
Rinse is a dishwasher app with one screen and one button. A study in taking things away until only the useful part is left.

Tags
Smart home · Product design · Branding

Intro (draft)
The official app tries to do everything at once: 5 tabs, 24 promoted tiles and a recipes section, in a dishwasher app. The one thing I do every night takes 4 taps to reach. Rinse keeps that one thing and puts it first.

Big line (draft)
Lights out, dishwasher on.
